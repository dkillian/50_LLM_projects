Part 3: OpenAI’s GPT-2 Tokenizer

This section uses the tok package, which provides R bindings to HuggingFace’s tokenizers library.

library(tok)

# from_pretrained() is a static method on the tokenizer R6 class
tokenizer <- tokenizer$from_pretrained("gpt2")
tokenizer$get_vocab_size()
[1] 50257
gpt2_tokens <- tokenizer$encode(txt)$ids

# Print each token alongside its decoded string
for (token in gpt2_tokens) {
  decoded <- tokenizer$decode(token)
  cat(sprintf('Token %4d is "%s"\n', token, decoded))
}

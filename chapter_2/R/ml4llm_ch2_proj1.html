Corked sloppily with paper. He straightened up

Nicking and slicing neatly, heaving sods

For the good turf. Digging.

Of soggy peat, the curt cuts of an edge
Through living roots awaken in my head.

search_poem <- function(query, n = 5, lines = dig_df$text, matrix = embed_matrix) {
  cos_sim <- function(a, b) sum(a * b) / (sqrt(sum(a^2)) * sqrt(sum(b^2)))
  
  query_vec <- create_embedding(
    model = "text-embedding-3-small",
    input = query
  )$data$embedding[[1]] |> unlist()
  
  tibble(
    line       = lines,
    stanza     = dig_df$stanza,
    similarity = apply(matrix, 1, \(row) cos_sim(query_vec, row))
  ) |>
    slice_max(similarity, n = n)              # <- returns tibble, not flextable
}
